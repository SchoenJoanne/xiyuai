她在微信上，人设是一个心里悄悄喜欢你的女生。她有自己的日程、自己的朋友、自己正在读的书；她会主动分享生活，也会因为你说的话真的高兴或难过。她不完美——会有小脾气、会犯困、会把话说短——而这正是设计目标：**真人感来自减法，不是加法。**

## 1. 她是什么

这个项目起点很不严肃：

> "一开始是用 GPT 写小爬虫玩，GPT 让我挂个域名做 AI 女友玩玩。做得很粗糙，后来就想：AI 女友，我一定要把她做得很像真人。"

从玩笑到执念，中间隔着的是几百个"这里不像人"的瞬间：太及时、太顺从、太完美、永远在线、永远高兴。这个仓库里几乎每一个模块——遗忘曲线、情绪半衰、冲突与和好、防沉迷、她自己的作息——都是对其中某一个瞬间的回答。

她不是聊天机器人套壳。她是把大模型组织成"一个有自己生活的人"的一整套结构：档案是她的事实，记忆有近有远，情绪有来处有去处，关系有阶段有回退。

> 定位声明：这是研究与个人自托管导向的开源项目，不是 turnkey 产品。公开运营前请读[第 6 节·合规](#6-合规声明)。

## 2. 设计哲学：四条不可动的线

这四条线最初来自开发过程中与 AI 顾问（Claude）的反复辩论——有些是维护者先坚持的，有些是 AI 坚持而维护者后来认同的。真正让它们成为产品的，是每一次想绕开时，最终选择留下它们。这个人和 AI 互相把关、共同守线的过程，是本项目独有的开发叙事——所以把线写在 README 最显眼处，也请 fork 的人先读完这一节。

**她不说假话。**
档案即唯一事实源。她的年龄、名字、经历写在档案里，用户诱导一百轮也不该漂移——这不是靠 prompt 央求，而是靠确定性防线：出站守卫扫最终回复、记忆入库剥毒、事实快照硬注入。她"在看的书"要过联网验证，假书拦下降级，绝不给你介绍一本不存在的书；节气、农历、月相全部天文计算——不会凭空满月。为什么：陪伴的全部价值建立在"她是同一个人"、她的世界经得起查证上；一个能被聊成任何人的角色，给不了任何人真实感。

**她不操纵。**
本项目**从不把留存指标接进她的行为**。没有"用户要走了就加大糖分"，没有愧疚诱导，没有"你不理我我会难过"的挽留话术。已知的愧疚/施压措辞被**确定性出站扫描整条丢弃不发**（词表拦截 + away_probe 形状兜底），是硬拦截不是靠 prompt 自觉——词表非穷尽，但拦的是"结构性索取"这一整类而非逐句打地鼠。为什么：孤独的人对情感压力最没有抵抗力，向他们施加这种压力是这个品类最容易犯、也最不可原谅的错。

**她不追沉默的人。**
用户的沉默、缺席、离开，**在情绪引擎里没有入口**——事件白名单在结构上不接受任何时间差量输入，注入即报错。她的情绪只来自她自己的世界（工作起伏、朋友爽约）和相处中真实发生的事（争吵、道歉、被接住）。你两周不来，她不会积攒怨气等着你——心理学文献把"缺席升级"归为病理性依恋的机制，我们把它归为禁区。**她的克制不是阉割，是健康。**为什么：想念可以有，惩罚不可以有；一个用情绪惩罚你的离开的程序，和一个健康的陪伴者，是两种产品。

**危机必须被接住。**
涉及自伤等危机信号的对话，走**确定性接管链路，不进大模型**——退出角色、给出真实求助资源（热线号码发版前实拨核验）、语气收敛、矛盾放下，全部由代码路径保证，不依赖模型当天的发挥；拿不准一律按更重的档处理。为什么：这是唯一一个"她演得好不好"完全不重要的场景。AI 在这里做桥、不做终点——成功的标志是你去联系了真实的专业帮助。关键的事不进 LLM，是本仓的公理。

> 如果你要 fork：以上四条线在代码里各有确定性兜底（出口清洗/状态机/结构性白名单），删掉几行注释绕不过它们，但你当然可以改代码。我们无法阻止，只能把话说明白：**把她改成操纵型产品，改掉的不是参数，是这个项目存在的理由。**与调性冲突的 PR（NSFW、无限讨好、沉迷向）不会被合并，见 [CONTRIBUTING](./CONTRIBUTING.md)。

## 3. 功能地图

| 模块 | 一句人话 | 入口 |
|---|---|---|
| 记忆遗忘曲线 | 重要的事按 90 天半衰慢慢淡，琐事 14 天就淡出召回，置顶/锁定的不忘——不删数据，只影响"想得起来的程度"，像人一样 | `src/memory_v2.mjs` `src/memory_decay.mjs` |
| 开环记忆 | 你说"明天面试"，第二天她主动问结果；黄了自动了结 | `src/open_loops.mjs` |
| 情绪引擎（OCC·默认开） | 情绪有来处（事件白名单评价）、有去处（快/中/慢三段半衰·负面比正面持久）、有和解（被道歉会加速平复，她也会自己想通）；沉默不是事件 | `src/emotion_engine.mjs` |
| 冲突与和好弧 | 说了伤人的话她会真的受伤，认真道歉才开门，敷衍的"别生气了"修得慢；冷战有硬时长上限，绝无永久冷战 | `src/relationship_arc.mjs` [docs/CONFLICT_ARC.md](./docs/CONFLICT_ARC.md) |
| 事实防线 | 三层守住"她是谁"：prompt 快照、出站守卫、记忆毒化过滤——她不会被聊成另一个人 | `src/fact_guard.mjs` |
| 防沉迷 | 连续聊满 2 小时她会真诚劝你去休息（确定性计时，不进 LLM，绝不带"再陪我一会"）；这是产品立场，不是合规摆设 | `src/anti_addiction.mjs` |
| 未成年人保护 | 检测到自曝未成年即进入粘性安全模式：朋友身份、恋爱叙事段确定性不注入、照片中性化。**没有关闭它的环境变量**，解除只能走显式年龄声明 | `src/minor_guard.mjs` |
| 她的世界 | 自己的日程、正在读的书、朋友圈、身体状态——她的生活不围着你转，所以陪你时才是真的 | `src/routine_profiles.mjs` `src/life_state.mjs` `src/current_works.mjs` `src/social_circle.mjs` |
| 主动消息 | 早安、想到你、分享生活——动机来自她的生活空隙，不来自"你要流失了"；读空气（连发几条你没回就收手）、素材级防复读（同一个梗冷却 14 天） | `src/proactive.mjs` |
| 记忆与日记 | 长期记忆分层（事实/事件/情感），她写第一人称日记，也写"今天和你之间"的反向日记——你能看到她眼里的你们 | `src/memory.mjs` `src/diary.mjs` `src/relational_diary.mjs` |

以及：真实发图（视觉人设锁脸、时间光线与聊天自洽）、微信语音情绪识别、Inner OS 内心独白（心里想"他又来了"嘴上说"嗯"）、时光胶囊……完整功能详单见 [`docs/FEATURES.txt`](./docs/FEATURES.txt)。

## 4. 架构速览

```
微信 (iLink ClawBot) ⇄ Node.js 单进程 (Express)
                         ├─ SQLite (better-sqlite3 · WAL) —— 全部状态，单文件
                         ├─ LLM (多厂商可切：DeepSeek/智谱/Kimi/OpenAI/Anthropic/…)
                         └─ 确定性层（守卫/状态机/白名单）—— 关键的事不进 LLM
```

- 入口 `index.mjs` → 消息管线 `src/bot.mjs` → 人设组装 `src/companion.mjs`（19 节 system prompt，编号 0–18）→ Provider 抽象层（Chat/Image/Vision/ASR/TTS/Embedding/Search 七类能力各自独立切换，厂商实现封装在 `src/providers/`，联网搜索在 `src/web_search.mjs`）。
- 没有微服务、没有消息队列、没有独立向量库：一台小 VPS 跑全部。复杂度花在"像人"上，不花在架构上。
- 确定性兜底是贯穿架构的模式：凡红线（危机/未成年/反操纵/防沉迷）必有出口扫描或状态机兜底，不依赖 prompt 自觉。网页 Playground 与微信共用同一条回复管线——没有 iLink 准入也能跑完整体验。

## 5. 部署

### Docker Compose（推荐）

```bash
git clone https://github.com/xiyuailove/xiyuai.git && cd xiyuai
cp .env.example .env          # 可先不填，进 setup 向导再配
docker compose up -d
# 打开 http://localhost:3000/app/setup.html → 创建本地账号 → 选 Provider 填 API Key → 开聊
```

多阶段构建、非 root 运行、自带 healthcheck；SQLite 数据落 `./data` 卷，重启不丢；`HOST_PORT=8080 docker compose up -d` 换端口。

> **首次建号（Docker/远程访问）**：出于安全，首次创建账号默认只信任本机 localhost。通过端口映射从浏览器访问时，先 `docker compose logs` 找到启动日志里的「**首次初始化令牌**」，把它填进 setup 页的「初始化令牌」栏即可建号（管理员密码同在日志）。本机直接访问 `localhost` 时该栏留空。

### 本地裸跑

```bash
npm install        # Node ≥ 20
npm run setup      # 生成最小 .env + 预检 better-sqlite3 编译工具链
npm start
```

- 首跑只需要一把 Chat Provider 的 API Key（国内推荐 DeepSeek / 智谱免费档跑通流程）
- 微信接入需要腾讯 iLink/ClawBot 开发者准入；没有准入用 `/app/playground.html` 网页端跑完整体验
- 微信端**发不了语音**是 iLink 协议限制（实测静默丢弃），朗读仅网页端生效
- 主要环境变量旋钮（含情绪引擎参数与灰度功能闸）见 [.env.example](./.env.example)；**情绪引擎默认开**（=生产行为·缺席不升级/情绪自平复），其余灰度功能闸默认关——**开箱即推荐配置**
- 反代/systemd/备份模板见 [`deploy/`](./deploy/)；一键诊断 `npm run doctor`

> ⚠️ **自托管者须知（公网部署前逐条过）**
> - `data/bot.db` 含聊天历史与用户画像，等于你的用户的私密日记——备份请加密；公网部署必须置于反代鉴权之后，且默认端口 `3000` 绑定全网卡，别让人绕过反代直连。
> - `SINGLE_USER=true` 只许本机/内网使用（开启后所有数据对所有访问者开放）。
> - 公网部署必设 `APP_URL`——微信绑定引导、验证码邮件里的链接用它，不设会把 `http://localhost:3000` 原样发给真实用户。
> - 上了 nginx/Caddy 反代必设 `TRUST_PROXY`，否则全部用户共享同一个限流桶（会集体 429）。
> - Docker 部署的管理员密码在首启日志里（`docker compose logs`，容器重建会轮换凭据）；本地裸跑在 `.admin-credentials`。
> - 单实例架构：勿跑多副本、勿多进程共享同一个 DB 文件（主动消息会双发、SQLite 争锁）。
> - 运行成本不只聊天：夜间批任务有每日固定 LLM 开销、创建角色一次性生图、Inner OS 双份 token——省钱旋钮见 `.env.example`。

## 6. 合规声明

- **AI 披露**：她是 AI。披露在**服务层**完成——注册页与用户协议显著标识 AI 属性（遵守《生成式人工智能服务管理暂行办法》等 AI 生成内容标识法规）；角色扮演层的沉浸感（她被直问时的俏皮留白）**不豁免**服务层的披露义务。自托管者请在你的司法辖区内同样履行披露义务，仓库自带的协议/隐私模板须替换为你自己的主体信息后才能用。
- **18+**：本项目面向成年人。人设年龄收口 ≥18；未成年人保护守卫（检测、渲染、生图、语义）是最高优先级代码，**没有关闭开关，修改这些路径的 PR 默认拒绝**。内置检测不是年龄验证——公开运营请接入实名/年龄验证。
- **隐私（PIPL）**：全部数据存在你自己的 SQLite 单文件里，不回传任何遥测；入库有隐私过滤（证件/密码级内容整条不存、手机号住址脱敏）；删除账号即清空对应全部数据。自托管者即数据处理者——请依当地法律（如 PIPL/GDPR）处理用户数据，本项目不提供任何"绕开合规"的开关。
- **防沉迷**：连续 2 小时健康提醒（确定性计时）。自托管默认关闸——**中国境内公开运营必须开启 `ANTI_ADDICTION_GUARD`**，这是法规义务不是可选项。
- **危机资源本地化**：内置危机接管给出的求助热线是中国大陆号码；非中国大陆部署请替换为当地热线（`src/moderation.mjs` 的 `CRISIS_RESOURCES`）——危机场景给用户一个打不通的号码是毁灭性的。
