# 停板A 设计稿：聊一半追一下 · topic 松绑 · proactive 拟人

> 分支 `design/topic-followup` · 仅设计·不施工·不碰生产。
> 来源：dogfood（用户发「在吗」聊一半走人 / topic 太苛刻 / 主动话题想更拟人）。
> 流程：盘点(4 路并行只读) → 设计 → **对抗式红队**（专攻"滑向 engagement/查岗"）。
>
> 🔴🔴 脊柱红线：**绝不因用户沉默升级 / 不查岗 / 不喂焦虑型上瘾**（维护者两天前亲手焊死「在吗在吗在吗」）。
> 唯一新增的合法主动面 = 「**用户自己开了话头然后走人 → 接住一次半截对话**」（一次·不升级·非凭空查岗）。

## 0. 🔴 红队结论先行（这才是停板A 的真信息）

设计方向成立，但红队（实读代码、落到行号）证伪出 **3 个 mustFix**，且其中一个直接打穿脊柱。**(A) 聊一半追一下 当前不能照请求直接做**——会滑回你焊死的线。诚实摆出：

| 红队攻击 | 严重度 | 发现 |
|---|---|---|
| **攻击2** | 🔴 mustFix | **脊柱条件「用户开口≠没理她的 proactive」在现有代码无承载字段**。`last_user_reply_at`/`clearProactiveUnanswered` 对两种情况**完全同形**（`bot.mjs:674` 无条件清零、`proactive_engine.mjs:465` 无条件更新）。后果：「她 proactive→用户回个『嗯』→4min 没下文」与「用户自主开话头后走人」**用现有字段无法区分**→ half_reply 会触发追问 = **因用户没理她而追 = 红线**。要做必须先加持久字段 `last_outbound_was_proactive`。 |
| **攻击3** | 🔴 mustFix | **3min 下界正落在"人离开手机"的生理常态间隔**（厕所/接水）。把 3min 沉默定义成"半截需被接住"，在焦虑型用户身上反复发生=训练"我一停她就紧张确认我在不在"=**喂焦虑的教科书节律**，且不依赖任何"在吗在吗"措辞就成立。而且「怎么了/在吗」**本就不在** `REDLINE_NEEDY_RE`（是放行词）。须：下界抬到 ≥5–6min + anxious 依恋桶更严/直接豁免。 |
| **攻击1** | 🔴 mustFix | **「只追一次」防得住单周期内重复，防不住"周期快速翻新"**。用户一回复即解锁下个周期（条件5），于是"反复欲言又止"的用户：丢半句→被追→回一句→又丢半句→又被追…… N 个半句=N 次追，客观上就是连环查岗、每次都踩在规则内。须加跨周期日配额（每会话/每日 half_reply ≤1–2）。 |
| 攻击4 | should | topic 安全性论证悬在 `topic_opener.mjs:86`（不在 main，无法核验）；拟人 reserved 暧昧档放松有"自来熟泛深情"回潮风险，词表非穷尽（`moderation.mjs:293` 自注打地鼠）。 |
| 攻击5/6 | nit/合规 | away_probe/lastcall/half_reply **时间窗物理不相交**（[8min,3h] 真空带为真）；不擅动他人分支=合规。这两条论证经核验**为真**。 |

**红队总评原话**：*"最致命的是攻击2：脊柱条件在当前数据模型里没有承载字段……这把整个 A 从『接半截』直接打回『可能因沉默查岗』。"*

🔴 **我的诚实判断（按"别为了有活干硬设计"纪律）**：(A) 你要的"追一下"是真机制缺口（away_probe 最低 3h、open_loop 只闭待办，确实没有"刚聊一半走"的接），值得做;**但它就是贴着你焊死的那条线**，安全版必须先补基础设施（proactive 标记字段）+ 抬下界 + anxious 豁免 + 日配额，四道缺一不可，且即便如此对最脆弱人群仍最毒。**(C) 拟人风险最低、纯文案、真有收益，建议先行。(B) topic 被单一事实源缺口硬阻塞，先拍协调路径再说。**

# (A) 聊一半追一下 — 红队加固版

## A.1 真机制缺口（盘点①坐实）
away_probe 最低 3h（恋人+anxious）+ 要 `AWAY_PROBE_MIN_AFFECTION=35` + 默认关；open_loop 只闭"待办事项"、冷却 6h。**「用户开话头+她回+用户 3–8min 消失」目前零机制**。所以不是 away_probe 调参能填的。

## A.2 触发定义（AND-gate·缺一不追）+ 🔴 红队加固
| # | 条件 | 现状可实现? | 加固 |
|---|---|---|---|
| 1. 用户**自己开的口**（末条 user 非对 proactive 的应答） | 🔴 **否·无字段**（攻击2） | **新增持久 `last_outbound_was_proactive`（或末条出站 kind），half_reply gate 硬读它**；不存在则条件1=纸面，整个 A 不许实现 |
| 2. 她已接住过（末条是她对用户的正常回复） | ✅ | 保留 |
| 3. **未自然收尾**（末条 user 不命中收尾白名单：晚安/睡了/先这样/明天聊/拜拜/下了） | 🔴 **白名单不存在**（红队证：净新增） | **新建可复用 `isFarewellClosing()` 函数 + 回归**，非口头声明 |
| 4. 窄窗 | ⚠️ 3min 太险 | **下界抬到 ≥5–6min·上界 8min 封死**（攻击3）；anxious 桶更严或豁免 |
| 5. 本半截只追一次 | ✅ 持久锁扛重启（攻击1 前半证实） | 保留 + **加跨周期日配额 ≤1–2/会话/日**（攻击1 后半） |
| 6. `proactive_unanswered < SILENCE_LIMIT` | ✅ 复用 `proactive_engine.mjs:355` | 保留·非豁免 kind·绝不进豁免清单 |
| 7. 下游闸全过（安全门>arc>夜间>硬间隔） | ✅ 复用 `sendProactiveMessageGuarded` | 保留 |

🔴 **条件 1+3+4+5 的加固项全是"实现前必须先建的基础设施"**，不是可选优化——红队证它们在 main 里都不存在，自检表当成了既成事实=空头。

## A.3 与 away_probe 分工（红队核验为真）
新 kind `half_reply_probe`（不污染 away_probe"纯生活锚/绝不提等待"的语气）。窗 [5–8min] vs away_probe [3h,21h]：**[8min,3h] 真空带物理隔离**（攻击5 证实不可能双发）+ 同 tick 单条闸。优先级 `reminder>lastcall>her_promise>half_reply>away_probe>normal`。

## A.4 「怎么了」语气（红队：最易翻车）
- 🔴 「怎么了/在吗」**不在** `REDLINE_NEEDY_RE`（放行词）→ 标准 scrub 拦不住。唯一防线= **净新增 `buildHalfReplyToneHint()` + away_probe 形状三槛**（≤1问号/≤4分句/≤35字），但形状槛拦不住"怎么啦~还在吗"这种合规形状/查岗内核。
- ✅ 允许：呼应用户上句情绪，一句、≤1问号、发完不需立刻回也成立（「怎么啦？」「在的呀，咋啦~」）。
- 🔴 禁：等待框架（你人呢/一直没等到/好久没回我）、催促质问（怎么不回/在不在连环）。命中即 **drop 不发**，绝不软化成更软的催促。

# (B) topic 条件松绑 — 单一事实源硬阻塞

## B.1 苛刻根因（盘点③）
四层 AND-gate 叠加：Ack-streak N=3 + 净长≤6字数字门 + 末条 bot 无钩子 + 每会话 M=1 + life_state 门控 + dogfood 默认 OFF。

## B.2 🔴 协调前置（待你拍·我不擅动）
```
topic_opener.mjs:  main ❌无  ·  生产 ✅有  ·  fix/proactive-topic 分支 ✅有
作息/life_state:   main ✅完整 ·  分支 ❌旧版(base 早于作息 merge 30b243e)
```
**倒三角 + 分支 base 过旧 = 改条件前的硬阻塞**：分支直接 merge 回 main 必炸作息系统（它把 routine_profiles 354 行当"删除"）；生产 dogfood OFF 也测不到。
🔴 **按会话间 PR 边界，`fix/proactive-topic` 是别会话的 OPEN 产出，我绝不 rebase/merge/改它。** 这步升级给你拍：(a) 先把 topic_opener 回库 main（带作息对齐）再改条件；还是 (b) 生产侧改+dogfood 验证后回库。**路径定了我才动参数。**

## B.3 松绑方向（路径确定后）

# (C) proactive 拟人「想说就说」— 风险最低·建议先行

## C.1 机械感根源（盘点④）
userMessage 给 6 个等值范例 bullet → AI 走安全模板（`proactive.mjs:1011-1024`）；反复读+reserved+想你 drop 三层叠床；morning「刚醒迷糊」vs reserved「端着」互否。

## C.2 最小改动（纯文案·不碰任何触发闸）
| 优先 | 改点 | 做法 | 红线保护 |
|---|---|---|---|
| P0 | userMessage 去范例 | 删 6 等值 bullet，换"按真实生活时段自然变化，没由头一句也好"，只留真坏模式禁忌（别老"刚…"、别连环问） | 保留"禁连环问/别工整播报" |
| P1 | reserved 按 stage 分叉 | 陌生/朋友禁"想你"；暧昧禁泛化想念**但允许有具体理由的关心**；恋人不注入 | 🔴 保留陌生/朋友"别说想你"底线 |
| P2 | 反复读只禁开场套路 | 只去重最近 2 条开场 5 字，删"意象"全面禁 | 保留"别两字同义复读" |
| P3 | morning 人设兜底对齐 | 刚醒语气随 persona/attachment 调，不与 reserved 打架 | 保留 confession 豁免/avoidant 端着 |

🔴 红线：只放松**措辞多样性**，SILENCE_LIMIT/安全门/arc/硬间隔/想你 drop **全不动**；保留并强化"不反问『你在干嘛/你那边呢』"（查岗入口）。
⚠️ 红队 should：P1 暧昧档放松前补"泛深情"回归用例（跑 ≥100 会话看自来熟率），不能只靠 `moderation.mjs:293` 自承非穷尽的打地鼠词表。
